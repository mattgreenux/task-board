How to make a token
  1. Open GitHub › New fine-grained token.
  2. Name it (e.g. “Task board”) and pick an expiration date.
  3. Resource owner: your account. Repository access: Only select repositories › TimeRush (the repository with the lists, not task-board).
  4. Permissions: under Repository permissions, set Contents to Read and write. (If you see an Add permissions button, click it, tick Contents, then change it to Read and write.) That's the only one needed: Metadata: Read-only turns on by itself, and nothing goes under Account permissions.
  5. Generate it, then paste it here on each device you use.

The token stays in this browser only. Anyone holding it can change TimeRush, so don't share it.
